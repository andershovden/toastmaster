Slik formaterer du dokumentet

Én overskrift per taler, og teksten under. Hvem som leser kan stå i overskriften eller på egen linje:

# Ola Nordmann (Anders)

Velkommen til vår neste taler ...

# Kari Nordmann
Leses av: Fredrik

Neste ut er ...

Overskrifter kan skrives som # Navn, ## Navn eller [Navn]. Leser kan angis med Leses av:, Leser:, Toastmaster: eller i parentes etter navnet. Tekst i [hakeparentes] vises som regibeskjed, f.eks. [vent på applaus].
